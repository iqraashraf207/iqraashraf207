### Adversarial Robustness of an ML Intrusion Detector
`Python` `XGBoost` `scikit-learn` `Adversarial Robustness Toolbox` `Jupyter`

Black-box evasion attack (HopSkipJump) and adversarial training study on an XGBoost DDoS detector (CIC-IDS-2017), built on the open-source xai-ids project. Found that the project's FGSM test cannot apply to tree models. Adversarial training raised the median perturbation an attacker needs about 3x but did not stop evasion.
